    Training Mode¶

    A key tool for new employees is being able to shift Commerce into a training mode that will allow new users to get familiar with the system with no worries about impacting the current day's sales.

    Concept¶

    • The system allows for an easy toggle between your live environment and the training mode.
    • The training mode gives full a full point of sale and back office experience.
    • Training mode transactions will not impact production sales or inventories.
    • Training mode transactions can be excluded from polling by configuration.
    • Training mode utilizes the same ID and passwords for all active cashiers.
    • All security roles, as found in production, are carried over in Training Mode.
    • Training mode also utilizes simulation for EFT/EMV credit transactions.

    Appearance¶

    This version of Commerce will operate the same as the production version will the exception of the clear training mode labeling.
